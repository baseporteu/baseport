    End-user authentication

    Authentication endpoints for your application at /auth and /api/auth/v1, distinct from administrative console accounts.

    Enables public authentication pages and API endpoints. Disabling this returns 404 responses for both.

    Allows new visitors to register accounts via /auth/register. This governs the password form only: a single sign-on provider with Create accounts on first sign-in turned on still provisions, because it trusts a directory you configured rather than the open internet.

    Lets a visitor try your app before signing up. POST /api/auth/v1/anonymous returns a token pair for a throwaway account with no credential; signing up while carrying that token claims the account, so the rows already created stay theirs.

    How long an unclaimed anonymous account is kept after its last session expired and nobody can reach it any more. Zero keeps them forever.

    The issuer identifier for the JWT. Beware, changing this value invalidates all active tokens.

    Duration an access token remains valid. Accepts values between 60 and 86400 seconds.

    Duration a refresh token can be exchanged for new access tokens. Accepts values between 1 and 365 days.

    Uses ES256. Expose /api/auth/v1/jwks.json for JWT middleware verification. Rotating this key logs out all users.
